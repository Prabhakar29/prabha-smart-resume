# Gnanaprabhakar Mahalingam — AI Portfolio & Resume

A modern, responsive, and component-based interactive portfolio built with **React** and **Vite**. This repository hosts the professional resume of Gnanaprabhakar Mahalingam, an Enterprise Java Architect and 100X Engineer Certified AI Architect.

## 🚀 Features

* **Interactive AI Chat Widget:** An integrated vanilla React chatbot that answers questions about Gnanaprabhakar's experience, skills, and projects in real-time.
* **Component-Based Architecture:** Modular design splitting the portfolio into distinct sections (`Hero`, `Experience`, `Projects`, `Skills`, etc.) for easy maintenance.
* **Scroll-Aware Navigation:** The top menu utilizes the `IntersectionObserver` API to automatically highlight the active section based on the user's current scroll position.
* **Modern UI & Animations:** Clean and dynamic styling with CSS variables, gradient effects, floating micro-animations, and scroll-triggered fade-ins.
* **Fully Responsive:** Adapts seamlessly to all screen sizes and mobile devices.

## 🛠️ Tech Stack

* **Framework:** [React 18](https://react.dev/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Styling:** Custom Vanilla CSS (`src/index.css`) with Google Fonts (Cormorant Garamond, DM Sans, JetBrains Mono).

## ⚙️ Local Development Setup

To run this project locally, ensure you have [Node.js](https://nodejs.org/) installed, then follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd prabha-smart-resume
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
   *This will generate a highly optimized static output in the `dist` folder.*
